Modul pengajaran dan pembelajaran digital interaktif selari dengan Competency Unit CU05 ADAS Diagnosis Level 4. Pilih tab modul di bawah untuk mengakses kandungan khusus.

Seksyen 1: Pengenalan & Latar Belakang Inovasi

Perkembangan teknologi kenderaan moden menuntut pelatih Latihan Teknikal dan Vokasional (TVET) dalam bidang Automotif untuk menguasai kemahiran mendiagnosis sistem kompleks seperti Advance Driver Assistance System (ADAS). Sistem ini merangkumi komponen seperti kamera pengesanan visual, sensor ultrasonik, radar dan LiDAR yang saling berkomunikasi dengan unit kawalan elektronik (ECU) kenderaan.

Cabaran Kenderaan Sebenar

Kos tinggi penyediaan kenderaan sebenar ber-ADAS serta risiko keselamatan pengendalian voltan tinggi membataskan peluang amali pelatih.

Penyelesaian SmartLine QR Rover

Platform robotik berskala mikro dan murah yang mensimulasikan kamera Traffic Sign Recognition (TSR) & Automatic Emergency Braking (AEB).

Seksyen 2: Objektif Modul & Hasil Pembelajaran

Projek ini bertujuan untuk mencapai hasil pembelajaran berikut:

  • Objektif 1: Membangunkan platform simulator robotik berautonomi SmartLine QR Rover menggunakan AI Vision (HuskyLens) dan sensor ultrasonik bagi mensimulasikan ADAS.
  • Objektif 2: Menyediakan modul PdP digital interaktif yang dipetakan secara langsung kepada standard NOSS G452-011-4:2025 (ADAS Diagnosis Level 4).
  • Objektif 3: Menyediakan pendedahan amali berskala mikro dan kos rendah sebelum pelatih mengendalikan kenderaan sebenar bervoltan tinggi.

Seksyen 3: Teori Navigasi & Pseudokod Logik Kawalan ECU

Rover beroperasi berasaskan 3 prinsip kawalan utama:

  1. Line Following Navigation: Sensor IR array membaca kontras garisan hitam pada trek permukaan.
  2. Obstacle Detection & AEB: Sensor Ultrasonik mengira masa balik gelombang bunyi untuk mengesan objek (< 20cm).
  3. AI Vision Command Recognition: HuskyLens membaca tag QR untuk menghantar arahan START, PAUSE & STOP menerusi komunikasi UART/I2C ke Arduino ECU.

Pseudokod Logik Kawalan (Arduino ECU):

// SmartLine QR Rover - ADAS Control Logic
VOID LOOP() {
    READ_HUSKYLENS_QR();
    READ_ULTRASONIC_DISTANCE();
    READ_LINE_SENSORS();

    IF (qr_command == "QR_START") {
        rover_state = STATE_RUNNING;
    } ELSE IF (qr_command == "QR_PAUSE") {
        rover_state = STATE_HOLD;
    } ELSE IF (qr_command == "QR_STOP") {
        rover_state = STATE_STOPPED;
    }

    // AEB Emergency Braking Priority Check
    IF (ultrasonic_distance < 20.0) { // Object in front < 20cm
        STOP_MOTORS();
        TRIGGER_HAZARD_ALARM();
        WAIT_UNTIL_PATH_CLEAR();
    } ELSE IF (rover_state == STATE_RUNNING) {
        EXECUTE_LINE_FOLLOWING();
    } ELSE {
        STOP_MOTORS();
    }
}

Seksyen 5: Manual Amali Terpandu & Diagnostik Kerosakan

Pelatih TVET dikehendaki melaksanakan 4 fasa ujian amali mengikut prosedur standard:

Prosedur Ujian Operasi Amali:

  1. Semakan Awal Sebelum Operasi: Semak sambungan talian kuasa bateri (7.4V DC), pin I/O sensor, dan mod pengesan HuskyLens.
  2. Ujian Sensor Garisan (Line Following): Tunjukkan kod QR START kepada HuskyLens dan perhatikan sama ada rover mengikut garisan trek secara tepat.
  3. Ujian Pengesanan Halangan (AEB Test): Letakkan objek pada jarak ~20cm semasa rover bergerak dan catat tindak balas henti automatik.
  4. Ujian Kawalan Kod QR (TSR Test): Tunjukkan kod QR STOP, START dan PAUSE secara berurutan dan perhatikan tindak balas ECU.

Soalan 2: Apakah tindak balas rover apabila sensor ultrasonik mengesan halangan pada jarak kurang daripada 20cm?
Soalan 3: Apakah unit kompetensi NOSS G452-011-4:2025 yang dipetakan bagi ujian pengesanan halangan ultrasonik?
Soalan 4: Sekiranya voltan bateri drop di bawah 4.2V dan sensor garisan gagal membaca trek, apakah Kod DTC yang disimulasikan?

Seksyen 7: Rumusan & Modul Pembangunan Lanjutan

SmartLine QR Rover membuktikan bahawa pendedahan sistem kenderaan autonomi dan diagnosis ADAS boleh diajar secara berkesan melalui kaedah simulasi skala mikro. Inovasi ini selari dengan keperluan pasaran buruh yang menuntut kepakaran mendiagnosis kenderaan berteknologi pintar (Industry 4.0).

Cadangan Pembangunan Lanjutan Masa Hadapan:

  • Mengintegrasikan sistem pelaporan Diagnostic Trouble Code (DTC) menerusi skrin scan tool OLED.
  • Mengembangkan modul untuk merangkumi simulasi sistem Radar & LiDAR (CU05-W01 & W04).
  • Penglihatan AI peringkat tinggi menggunakan model YOLOv5 terbenam pada Raspberry Pi.
